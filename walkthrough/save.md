# Format on save

The command "Shell Formatter: Turn On Format on Save for Shell Scripts" adds this to your user settings:

```json
"[shellscript]": {
  "editor.defaultFormatter": "zovo.zovo-shell-formatter",
  "editor.formatOnSave": true
}
```

A script with a syntax error is saved as it is. The error shows in the Problems panel, and the status bar item turns yellow.
